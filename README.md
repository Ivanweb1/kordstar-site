# Кордстар — главная страница

Статическая копия страницы с Тильды (designcordstar.tilda.ws, «Copy of Blank page»), собранная из сохранённого MHTML.

- `index.html` — разметка страницы (родная разметка Тильды, очищенная от служебных инлайн-стилей)
- `css/page.css` — все стили страницы в исходном порядке; `css/fixes.css` — правки поверх
- `js/main.js` — масштаб Zero-блоков, появление при скролле, меню, слайды + перенесённые скрипты страницы
- `img/` — картинки из файла. С CDN Тильды грузятся только фоновое видео первого экрана и фото «Дарья» (их не было в файле)
- `tools/convert.py` — одноразовый конвертер MHTML → проект

Превью: `python -m http.server 4450` в папке проекта.

## Главная в один вайб-блок Тильды

`python tools/tilda_block.py` → `tilda/kordstar-main.html` — весь код страницы (разметка, CSS, скрипт)
для одного вайб-блока (tpl 1370). Проверка: `tilda/preview.html`.

- лишний CSS выкидывается, селекторы ограничены контейнером `.vb-krd`, длинные номера Тильды заменены короткими метками;
- картинки — с CDN Тильды; 14 штук, которых там не нашлось, — с GitHub Pages этого репо;
- после правок в `index.html` / `css/` / `js/main.js` блок надо пересобрать и вставить заново.

## Поп-апы заявок

Шесть кнопок открывают свои поп-апы (атрибут `data-krd-popup` на кнопке → `#krd-pop-<имя>` в конце `index.html`):

| Кнопка | Поп-ап | «Форма» в заявке |
|---|---|---|
| Первый экран — «Получить расчёт стоимости» | `calc` | Расчёт стоимости |
| Первый экран — «Связаться с нами» | `contact` | Связаться с нами |
| «Почему клиенты выбирают» — «Оставить заявку» | `pick` | Помощь с подбором |
| «Контроль качества» — «Запросить документацию» | `docs` | Запрос документации |
| «Сделайте первый шаг» — «Оставить заявку» | `start` | Подбор каната |
| «Остались вопросы?» — «Задать вопрос» | `question` | Вопрос |

Стили — `css/popups.css`, логика — `js/main.js`, раздел 11.

**Как заявки попадают в Тильду** (схема как на fulfil.pro): своего приёмника у поп-апов нет. Скрипт берёт
обычную форму Тильды на этой же странице, переписывает в неё имя и телефон, добавляет скрытые поля
«Форма», «Детали» (всё остальное из поп-апа) и «Страница» и нажимает её кнопку — дальше Тильда
отправляет заявку во все подключённые приёмники (почта, Telegram, CRM). Блок с этой формой скрипт прячет сам.

Что сделать в Тильде на странице:
1. Добавить любой блок с формой (например, T678) с полями «Имя» и «Телефон» и подключить у него приёмники данных.
   У поля «Имя» лучше тип «Текст», а не «Имя».
2. Блок НЕ скрывать галочкой «Скрыть блок» — тогда его нет в разметке, и заявки уйдут в никуда.
3. У формы не ставить «Перенаправление после успеха» — иначе после заявки посетителя уведёт со страницы.
4. Опубликовать и отправить тестовую заявку (имя «Тест»): на GitHub Pages и локально формы Тильды нет,
   там поп-ап только показывает «Заявка отправлена» (демо-режим), ничего не отправляя.

Если заявка не ушла — в консоли браузера сообщение с префиксом `[krd]`, текст ошибки в `window.KRD_LAST_ERROR`.
