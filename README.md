# Кордстар — главная страница

Статическая копия страницы с Тильды (designcordstar.tilda.ws, «Copy of Blank page»), собранная из сохранённого MHTML.

- `index.html` — разметка страницы (родная разметка Тильды, очищенная от служебных инлайн-стилей)
- `css/page.css` — все стили страницы в исходном порядке; `css/fixes.css` — правки поверх
- `js/main.js` — масштаб Zero-блоков, появление при скролле, меню, слайды + перенесённые скрипты страницы
- `img/` — картинки из файла. С CDN Тильды грузятся только фоновое видео первого экрана и фото «Дарья» (их не было в файле)
- `tools/convert.py` — одноразовый конвертер MHTML → проект

Превью: `python -m http.server 4450` в папке проекта.
